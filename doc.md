# Project Context

## Project

Commercial landing page for a local washing machine repair service.

The objective is not visual experimentation.

The objective is to maximize trust, SEO quality, loading speed and lead conversion.

The result should look handcrafted by an experienced web studio, not generated by AI.

---

# Priority Order

Always prioritize tasks in this exact order.

1. Conversion
2. Technical SEO
3. User Experience
4. Performance
5. Responsive Layout
6. Visual Polish
7. Small Animations

Never sacrifice higher priority items for lower priority ones.

---

# Token Budget

Do not waste tokens.

Avoid overthinking.

Avoid unnecessary abstractions.

Avoid enterprise architecture.

Avoid explaining your decisions.

Avoid generating documentation.

Avoid long comments.

Focus only on production-ready code.

---

# Design Philosophy

The design should communicate:

cleanliness

freshness

professionalism

trust

home comfort

precision

reliability

The visitor should subconsciously associate the visual style with:

clean water

soap

fresh laundry

bright bathroom

professional technician

comfortable home

European service quality

---

# Visual Style

The design MUST NOT resemble a typical AI-generated website.

Avoid:

- startup SaaS layouts
- huge gradients
- glassmorphism
- neumorphism
- floating decorative blobs
- neon colors
- dark interfaces
- exaggerated rounded corners
- fake dashboards
- random illustrations
- excessive shadows
- giant empty hero sections
- overdesigned animations

The page should look calm, premium and believable.

---

# Color Strategy

Primary

White

Secondary

Very light cool gray

Accent

Fresh aqua / washing water blue

Approximate accent

#11B8D9

Accent color should be used sparingly.

White should dominate.

The interface must feel airy.

---

# Typography

Readable.

Modern.

Neutral.

Professional.

Comfortable spacing.

Excellent hierarchy.

No oversized headlines.

No tiny text.

---

# Layout

Wide but not oversized.

Consistent spacing.

Balanced whitespace.

Maximum content width around 1200px.

Good vertical rhythm.

No visual clutter.

---

# Images

Use realistic placeholders only.

Examples:

Technician repairing washing machine

Modern washing machine

Happy family

Clean laundry

Repair process

Use descriptive alt text.

Lazy loading where appropriate.

---

# SEO

Generate proper semantic HTML.

Use:

title

description

canonical

OpenGraph

Twitter Card

robots

JSON-LD

LocalBusiness

Service

FAQ schema where appropriate.

Correct heading hierarchy.

Semantic sections.

---

# Forms

Prepare forms only.

No backend.

No API.

No submission logic.

The forms must be easy to connect later.

---

# Lead Capture

There should be multiple opportunities to contact.

Examples:

Hero CTA

Sticky mobile CTA

Small floating contact widget

Full contact form

CTA after services

CTA after FAQ

Never force the visitor to scroll back.

---

# Animations

Very subtle.

Hover.

Fade.

Button interaction.

No animation should distract from conversion.

---

# Mobile

Large buttons.

Easy forms.

Readable typography.

No horizontal scrolling.

Excellent touch targets.

---

# Code

Pure HTML

Pure CSS

Vanilla JavaScript

Readable.

Maintainable.

Minimal.

No unnecessary abstractions.

No frameworks.

No dependencies.

Everything should work immediately after opening index.html.

---

# Content

Marketing copy is NOT the priority.

Use concise placeholder text.

Spend effort on layout, structure, hierarchy, SEO and conversion.

---

# Final Goal

If a professional web agency built a premium landing page for a washing machine repair company in Europe, the result should closely resemble that quality.

Every decision should support one or more of these goals:

Increase trust.

Increase conversion.

Increase perceived professionalism.

Improve SEO.

Improve loading speed.

Reduce visual noise.
